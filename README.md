# ctos-web

ChingTech OS 新前端（React）— 擎添工業內部系統的 Web 介面。

目前為 Vite + React + TypeScript + Tailwind CSS + shadcn/ui 的骨架，部署於 https://os.ching-tech.com 。

## 開發

```bash
npm install
npm run dev
```

## 建置

```bash
npm run build
```

輸出於 `dist/`，由 GitHub Actions（`.github/workflows/deploy.yml`）部署到 GitHub Pages。
